Re-encodes a video as a 399 fps VP9 stream: one frozen mosaic frame, with each real 30 fps frame shown for a single 2.5 ms slot.

Faithful mode is a two-pass encode at roughly 12 slots per second for a 1080x1920 source, so a two minute clip takes about an hour. Jobs run one at a time; you can queue several.
